\noindent\textbf{本部分导言。}
本书所说的“前沿”，指大约 2010 年以后出现、其地位仍在变化之中的结果：有的已有完整证明，但只在预印本中给出；有的是全阶论证，关键的一步仍是被明确假定的；有的只在模型、某个固定阶或数值上得到检验。第一至第六部分建立的分级（\tagR、\tagA、\tagP、\tagC、\tagV）与编号假设在这里同样适用，并且执行得更严：一个结果的等级只依据我们实际读过的内容；只读过摘要的文献，其内容一律以“据该文摘要”引出或加以限定；只以 arXiv 预印本形式存在的文献在每章首次引用处与有关的“地位与缺口”段落中注明“（预印本）”；证明只见于预印本的结果，除非本书完整地写出其证明，否则不评为 \tagR。格点与模型计算始终是证据，而不是证明。

本部分分为三章。\cref{ch:lamet}讨论大动量有效理论与短距离因子化——季向东（Xiangdong Ji）及其合作者开创的、由欧氏格点计算光锥量的途径：准分布与赝分布、类空 Wilson 线算符的重整化、匹配定理及其编号假设、Fourier 步骤与幂次修正，以及准 TMD 因子化与格点 Collins--Soper 核。\cref{ch:yzliu}介绍 Yizhuang Liu（独自及与合作者）把 TMD 与 LaMET 因子化中的若干论证推进到定理层次的工作：作为重夸克形状因子的欧氏软函数、复双曲角中的解析性与时序无关性、本征软函数、准 PDF 匹配核的阈值因子化，以及在可精确求解的二维模型中的检验。\cref{ch:front}汇集其他方向的严格进展：Landau 方程与钳夹判据、OPE 的严格结果、区域方法与隐藏区域、Glauber 有效理论与超领头对数、次领头幂次的端点因子化、$\MSbar$ PDF 的正定性之争、非定域算符的 BRST 分类、小 $x$、双部分子散射、喷注与非全局对数、重夸克偶素，以及 QED 与电弱修正。三章之间的依赖只沿书的顺序进行；后面章节中的结果在前面只作为正文中的指引出现。
