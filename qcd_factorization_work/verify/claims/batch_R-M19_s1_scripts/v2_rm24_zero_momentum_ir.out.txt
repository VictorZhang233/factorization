G(1,1) = 2**(2*epsilon - 1)*pi**(3/2)/(P2**epsilon*sin(pi*epsilon)*gamma(3/2 - epsilon))
G(2,1) (doubled propagator = zero-momentum insertion) = -4**epsilon*pi**(3/2)*P2**(-epsilon - 1)/(sin(pi*epsilon)*gamma(1/2 - epsilon))
(-p^2) * G(2,1) = -pi**(3/2)*(4/P2)**epsilon/(sin(pi*epsilon)*gamma(1/2 - epsilon))
   expanded at fixed p^2 != 0: log(P2) + EulerGamma - 1/epsilon
(-p^2) * G(1,1) expanded       : P2*(epsilon*(-log(P2) - EulerGamma + 2) + 1)/epsilon
   (-p^2) G(1,1): coefficient of 1/eps = P2 (limit p^2->0: 0);  eps^0 coefficient = P2*(-log(P2) - EulerGamma + 2) (limit p^2->0: 0)
   (-p^2) G(2,1): coefficient of 1/eps = -1 (limit p^2->0: -1);  eps^0 coefficient = log(P2) + EulerGamma (limit p^2->0: -oo)
=> p^2 x G(1,1) -> 0 on shell (log at worst), but (-p^2) x G(2,1) = -1/eps + ln(-p^2) + gamma_E + O(eps) does NOT vanish as p^2 -> 0:
   the "factor of zero" is compensated exactly when the insertion carries zero momentum (forward kinematics).
