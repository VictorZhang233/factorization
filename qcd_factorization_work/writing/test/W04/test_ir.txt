注 1.5（Landau 条件的充分性与整体形变 A 全阶论证 ） 完整的钳夹理论还需要三点：(a) 充分
性——若 k0 处存在 αj ≥ 0 的 Landau 解，则任何容许形变（包括一阶位移为零的“反常”形
变）都不能避开 k0 处的奇点，即围道被钳住；(b) 整体形变——在不含钳夹点的区域上，各点
的局部形变可以借助单位分解拼接为一个整体的容许形变，从而把积分围道推离一切未被钳住
的奇异面；(c) 以上只涉及有限圈动量处的奇异性，第二类奇异性（U = 0，圈动量趋于无穷）不
在讨论之列。注意“被钳住”不等于“积分奇异”：Landau 条件对围道的钳夹是充要的（在下
述地位之下）
     ，对积分作为外部参数的奇异性只是必要的——无质量自能对一切 p 都在 k = 0 与
k = p（零动量线）处被钳住，却只在 p2 = 0 处奇异。

   前几节从钳夹面出发确定区域：先由 Landau 方程与 Coleman–Norton 图像找出可能的长程
