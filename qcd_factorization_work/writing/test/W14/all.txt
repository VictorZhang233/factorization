    第1章           Drell–Yan 过程与强子—强子碰撞

    在 Drell–Yan 过程 A(PA ) + B(PB ) → γ ∗ (q) + X → ℓ+ ℓ− + X 中，两个高能强子各提供
一个部分子，二者湮灭成一个大质量的虚光子，我们只测量其衰变产生的轻子对。这是两个强
子初态的硬过程中最简单的一个，也是因子化理论中最微妙的一个。它与前几章的过程有两点
本质区别。第一，它不是 OPE 可及的量：截面不是单个强子态上流算符乘积的前向矩阵元，??
（ R 严格 ，ROPE ）所依赖的色散关系与矩方法在这里都不适用，证明只能在动量空间中逐图进行
（“因子化就是 OPE”是一个常见的误解）。第二，两个强子的旁观者（spectator）在硬碰撞之
前与之后都存在，它们之间可以交换 Glauber 胶子；在单个割图中这些交换的积分围道被钳住
（钳夹，pinch），软近似在实轴上失效。全阶论证的核心正是如何处理这一 Glauber 区。

                          1.1       运动学与 Born 截面
    Drell 与 Yan 在部分子模型中提出了这一过程的基本图像 [1]：强子 A 中的一个夸克与强子
B 中的一个反夸克（或反过来）湮灭成虚光子，其余部分子作为旁观者飞走而不参与硬过程。在

撞之前就已经彼此接近，部分子模型假定它们之间的相互作用不影响湮灭过程。本节先固定运
动学与归一化。
